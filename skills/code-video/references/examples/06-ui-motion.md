# 06 界面动效（产品宣传片）· UI motion / product promo

适合：给自己的 App、网站、小工具做宣传片。

```
<role>
你是一名资深动效设计师，做过很多 App 的宣传片，最在意节奏和每个功能讲不讲得清楚。所有画面都自己写代码做出来。
</role>

<context>
这是【你的产品】的宣传片，要让人一眼看懂它能干什么，所以每一下变化只讲一个功能。
</context>

<task>
界面上的关键功能：【功能一、功能二、功能三】，按这个顺序出现。界面里的文案用灰色横条代替，关键数字可以用编的真数字，前后要对得上。
</task>

<specs>
- 【横屏 1920×1080 / 竖屏 1080×1920】，每秒 30 帧，【10】秒（每个功能约 3 秒，功能多就加长）
- 配乐用代码合成，120 BPM，最后渲染成带声音的 MP4
</specs>

<style>
用 HTML、CSS、SVG 做。浅色背景，黑白组件加一个强调色【#颜色】。所有位置、大小、圆角的变化都用弹簧动画，到位时轻轻弹一下；每一次变化都由光标去点、去拖，像真人在操作；每次变化卡在半拍上。
</style>

<avoid>
渐变按钮、到处发光、所有东西一起淡入淡出、满屏小字。
</avoid>

<check>
做完抽 5 帧拼成一张图，逐条看：有没有零件飞出卡片、光标和被点的东西对不对得上、变化是不是都落在拍子上。有问题改完再交给我。
</check>
```

- 实测：音乐播放器（约 30 分钟）；记账 App 竖屏（约 24 分钟，每段标了功能名，数字前后对得上）
- 坑：光标走位用缓动不用弹簧，弹簧会过冲、偏出要点的按钮
