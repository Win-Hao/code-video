# 03 复古街机（像素 + 老电视）· Retro arcade

适合：开场、怀旧、游戏感。就是像素画面外面套一层老电视屏幕。

```
<role>
你是一名像素美术，也是懂老电视显像管效果的技术美术，最在意怀旧的质感，同时主角始终看得清。所有画面都自己写代码画出来。
</role>

<context>
这是一段【开场 / 怀旧短片】，要有老街机开机的感觉，观众在手机上看。
</context>

<task>
【场景和主角，天上或背景里有什么在动】
</task>

<specs>
- 【横屏 1920×1080 / 竖屏 1080×1920】，每秒 30 帧，【8】秒，动作不重复
- 全部用代码画，最后渲染成 MP4
</specs>

<style>
分两层做。第一层用 Canvas 画像素画：画在很小的画布上（横屏 256×144，竖屏 144×256），整数倍放大、关掉平滑，颜色不超过 16 种。第二层把整个画面当纹理，叠一层老电视着色器：弧形屏幕、扫描线、荧光点阵、泛光、暗角、轻微闪烁。第二层只是给现成的画面套一块旧屏幕，不要重画。
</style>

<avoid>
画面里写字（招牌只画图形）、真实游戏里的角色、泛光把主角糊成一团。
</avoid>

<check>
做完抽 5 帧拼成一张图，逐条看：套上老电视效果后主角还认不认得出、泛光有没有把形状糊掉、弧形屏幕的边有没有切到主角。有问题改完再交给我。
</check>
```
