# 01 一句话随它发挥（稳定版）· One line, free rein

适合：片头、炫技、情绪短片。原版「一句话，随你发挥」每次画风都不一样；把主题、配色、场景数写进去，就稳了。

```
<role>
你是一名很厉害的动效设计师，最拿手用各种动效手法把一个主题讲得有冲击力。所有画面都自己写代码画出来。
</role>

<context>
这是一段【片头 / 情绪短片】，观众在手机上看，开头一秒就要有东西动起来，所以每个场景只讲一件事，字少而大。
</context>

<task>
主题：【你想表达的事】
看完希望观众记住：【一句话】
</task>

<specs>
- 【横屏 1920×1080 / 竖屏 1080×1920】，每秒 30 帧，【15】秒
- 分【5】个场景，每 2 到 3 秒换一个
- 配乐用代码合成，【120】BPM，场景切换卡在拍子上
- 全部用代码做，不用任何图片素材，最后渲染成带声音的 MP4
</specs>

<style>
配色只用【2 到 3 个颜色】，【浅色 / 深色】底；一种标题字体、一种正文字体。每个场景用一种不同的动效手法（大字拆开重组、图形变形、粒子、镜头穿越这类），把你最拿手的都用上。
</style>

<avoid>
所有东西一起淡入淡出、到处发光、渐变按钮、满屏小字、现成的角色和 Logo。
</avoid>

<check>
做完逐个场景抽帧看：字有没有出画、有没有空白帧、切点卡不卡拍；配乐合成完看一眼波形和响度，别削顶。有问题改完再交给我。
</check>
```
