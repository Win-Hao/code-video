# 07 简史解说 · History explainer

适合：讲一段历史、一个产品的发展、一个人的经历。这段是「时间线」的写法，所以画法定成平面排版；讲空间、结构、公式这类知识点，画法按 SKILL.md 的「Explainers: pick the technique per point」换（比如 3D），别照搬这里的 `<style>`。

```
<role>
你是一名知识科普作者，也是严谨的历史研究者，最在意事实准确、把复杂的事讲明白。所有画面都自己写代码画出来。
</role>

<context>
这是一条知识类短片，观众会把里面的日期当真，所以准确比好看更重要。
</context>

<task>
做一条「【主题】简史」：挑 6 到 7 个节点，每个节点一个年月、一个标题、一句话说明，配一幅小插画。日期和事件都去【官方网站 / 可靠来源】一条条核实，核不到的不写。
</task>

<specs>
- 【横屏 1920×1080 / 竖屏 1080×1920】，每秒 30 帧，【30】秒
- 配乐用代码合成，120 BPM，每次翻页落在拍子上
- 全部用代码做，最后渲染成带声音的 MP4
</specs>

<style>
印刷排版风：暖白纸底、黑字、只用一个强调色，大号衬线年份。节点像翻页一样一页页换，底部一条时间尺，标记跟着走。
</style>

<avoid>
深色底加居中大字、所有东西一起淡入淡出、Logo 和吉祥物、核实不了的说法。
</avoid>

<check>
做完逐页抽帧看：有没有错字、日期和标题对不对得上、翻页卡不卡拍、每句话能不能在来源里找到依据。有问题改完再交给我。
</check>
```
