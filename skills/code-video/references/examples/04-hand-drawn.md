# 04 手绘绘本 · Hand-drawn picture book

适合：温柔的小故事、治愈系。七种里最慢，约一小时。

```
<role>
你是一名绘本插画师，擅长温柔、有手作感的画面，最在意线条的手绘味和画面的氛围。所有画面都自己写代码画出来。
</role>

<context>
这段是【用在哪】，要像绘本里的一页动了起来，温柔、有手作感，观众在手机上看。
</context>

<task>
【场景，主角在做什么，环境里有什么在动】
</task>

<specs>
- 【横屏 1920×1080 / 竖屏 1080×1920】，【8】秒，最后渲染成每秒 30 帧的 MP4
- 全部用代码画，不用任何图片素材
</specs>

<style>
用 p5.js 加 p5.brush 笔刷画：纸张纹理的底、铅笔勾线、水彩上色。画面一秒只换 12 张，每张线条轻轻抖一下，手绘动画的生气就来自这种抖。
</style>

<avoid>
纯黑背景、到处发光、干净得像矢量图的线条、已有的角色和 Logo。
</avoid>

<check>
做完抽 5 帧拼成一张图，逐条看：主角比例对不对、天气和光这些氛围够不够（比如下雨要一眼看得出在下雨）、线条有没有在抖。有问题改完再交给我。
</check>
```
